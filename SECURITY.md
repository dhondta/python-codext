# Security Policy

## Supported Versions

Only the latest release of CodExt (`codext` on [PyPI](https://pypi.org/project/codext/)) receives security fixes.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Instead, report them privately through [GitHub's private vulnerability reporting](https://github.com/dhondta/python-codext/security/advisories/new) (the repository's *Security* tab, then *Report a vulnerability*). Please include:

- the CodExt and Python versions;
- the steps to reproduce the issue (codec name, input and the command or code used);
- the impact you expect.

You will get an answer as soon as possible. Once the issue is confirmed, a fix is released and the advisory is published.
