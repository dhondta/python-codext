`codext` can generate and read matrix and stacked barcodes. The `aztec`, `datamatrix`, `pdf417` and `qr` codecs produce real, scannable Aztec, Data Matrix, PDF417 and QR codes (with Reed-Solomon error correction), while `fakeqr` only mimics the aspect of a QR code, hiding the input in an image that is not a valid one.

-----

### Aztec Code

This encodes the input as a real (standard, scannable) [Aztec code](https://en.wikipedia.org/wiki/Aztec_Code) (ISO/IEC 24778), a 2D matrix barcode with a central bulls-eye finder pattern and the data spiralling around it. It uses the optimal high-level compaction (upper, lower, mixed, punctuation and digit modes plus binary shift), selects the smallest symbol (compact 1 to 4 layers, then full 1 to 32 layers) that fits the data for the chosen error correction percentage (given in the codec name, 23% by default) and adds the Reed-Solomon error correction. Decoding recovers the size, layer count and error correction from the mode message and applies Reed-Solomon error correction, so that a damaged code can still be decoded ; it handles all the compaction modes, so that Aztec codes generated by other tools can be read. Like the other barcodes, the output is a grayscale PNG image by default, or plain text with the `-text` variant.

**Codec** | **Conversions** | **Aliases** | **Comment**
:---: | :---: | --- | ---
`aztec` | text <-> Aztec code (image or text) | `aztec-N` (*N* being the error correction percentage), `aztec-text`, `aztec-N-text` | 23% by default ; the symbol size is chosen automatically

```python
>>> png = codext.encode(b"codext", "aztec")
>>> png[:8]
b'\x89PNG\r\n\x1a\n'
>>> codext.decode(png, "aztec")
b'codext'
```

### Data Matrix

This encodes the input as a real (standard, scannable) [Data Matrix](https://en.wikipedia.org/wiki/Data_Matrix) barcode (ISO/IEC 16022, ECC200), recognizable by its "L"-shaped solid finder pattern and the dashed timing pattern on the two other sides. It encodes the data with the most compact of the ASCII (with digit-pair and extended-ASCII optimizations), C40, Text, X12 and EDIFACT schemes, selects the smallest symbol (square, or rectangular with the `-rect` variant) that fits and adds the Reed-Solomon error correction. Decoding reads the symbol back and applies Reed-Solomon error correction, so that a damaged code can still be decoded ; it handles every encodation scheme (including Base256), so that Data Matrix codes generated by other tools can be read. Like the other barcodes, the output is a grayscale PNG image by default, or plain text with the `-text` variant.

:---: | :---: | --- | ---
`datamatrix` | text <-> Data Matrix (image or text) | `data-matrix`, `dmtx`, `datamatrix-rect`, `datamatrix-text`, `datamatrix-rect-text` | square by default ; the symbol size is chosen automatically

```python
>>> png = codext.encode(b"codext", "datamatrix")
>>> png[:8]
b'\x89PNG\r\n\x1a\n'
>>> codext.decode(png, "datamatrix")
```

### Fake QR Code

This hides the input bytes in something that looks like a [QR code](https://en.wikipedia.org/wiki/QR_code) but is not a valid one: each bit becomes a module (a dark module for a 1, a light one for a 0), laid out row by row in the smallest QR-like square grid (versions 1 to 40) that can hold them while skipping the three finder patterns (the corner squares) and the timing patterns (the dotted lines joining them), so that the result keeps the typical QR aspect. A 32-bit header holds the input length. An optional mask (one of the 8 QR mask patterns, given in the codec name) inverts part of the data modules depending on their coordinates, making the pixels look more random. By default, the fake QR code is a grayscale PNG image (one pixel per module), but the `-text` variant renders it as plain text instead, with a full block for a dark module and a space for a light one ; decoding accepts either form.

**Codec** | **Conversions** | **Aliases** | **Comment**
:---: | :---: | --- | ---
`fakeqr` | text <-> fake QR code (image or text) | `fakeqr-N`, `fakeqr-text`, `fakeqr-text-N` (*N* being the mask pattern) | no mask by default ; *N* ranges from 0 to 7

```python
>>> png = codext.encode(b"this is a test", "fakeqr")
>>> png[:8]
b'\x89PNG\r\n\x1a\n'
>>> codext.decode(png, "fakeqr")
b'this is a test'
>>> codext.decode(codext.encode(b"this is a test", "fakeqr-3"), "fakeqr-3")
b'this is a test'
>>> print(codext.encode("test", "fakeqr-text"))
```

### PDF417

This encodes the input as a real (standard, scannable) [PDF417](https://en.wikipedia.org/wiki/PDF417) barcode (ISO/IEC 15438), a stacked linear barcode made of rows of 17-module code words. It encodes the data with the most compact of the Text, Byte and Numeric compaction modes, chooses the number of columns automatically and adds the Reed-Solomon error correction (over GF(929)) at the level given in the codec name (0 to 8 ; 2 by default). Decoding reads the symbol back and applies Reed-Solomon error correction, so that a damaged code can still be decoded ; it handles the three compaction modes, so that PDF417 barcodes generated by other tools can be read. Like the other barcodes, the output is a grayscale PNG image by default, or plain text with the `-text` variant.

**Codec** | **Conversions** | **Aliases** | **Comment**
:---: | :---: | --- | ---
`pdf417` | text <-> PDF417 (image or text) | `pdf-417`, `pdf417-N` (*N* being the error correction level), `pdf417-text`, `pdf417-N-text` | level 2 by default ; the number of columns is chosen automatically

```python
>>> png = codext.encode(b"codext", "pdf417")
>>> png[:8]
b'\x89PNG\r\n\x1a\n'
>>> codext.decode(png, "pdf417")
b'codext'
>>> print(codext.encode("Hi", "pdf417-0-text"))
```

### QR Code

This encodes the input as a real (standard, scannable) [QR code](https://en.wikipedia.org/wiki/QR_code), as opposed to the `fakeqr` codec which only mimics the aspect of one. It uses the byte mode, selects the smallest version (1 to 40) that fits the data for the chosen error correction level (`L`, `M`, `Q` or `H`, given in the codec name, `M` by default) and picks the data mask with the lowest penalty score. Decoding reads the QR code back, recovering its error correction level and mask from the format information and applying Reed-Solomon error correction, so that a damaged QR code can still be decoded ; it also handles the numeric and alphanumeric modes, so that QR codes generated by other tools can be read. Like `fakeqr`, the QR code is a grayscale PNG image by default, or plain text with the `-text` variant.

**Codec** | **Conversions** | **Aliases** | **Comment**
:---: | :---: | --- | ---
`qr` | text <-> QR code (image or text) | `qr-L`, `qr-M`, `qr-Q`, `qr-H`, `qr-text`, `qr-H-text` | `M` by default ; the mask is chosen automatically

```python
>>> png = codext.encode(b"codext", "qr")
>>> png[:8]
b'\x89PNG\r\n\x1a\n'
>>> codext.decode(png, "qr")
b'codext'
```
